## About project
Pearl Muse shop
Pearl Muse Shop is an online store for handmade jewelry.The project is developed using Laravel and provides the basic functionality of an online jewelry shop.


## Used technologies
- PHP
- Laravel
- Blade
- MySQL
- JavaScript
- Node.js
- Laravel Breeze


## Installation

- git clone https://github.com/voevodovaj/pearlmuse.git
- cd pearlmuse
- composer install
- npm install
- create MySQL database
- create `.env` file and configure database connection
- php artisan key:generate
- php artisan migrate
- npm run build
- php artisan serve

After that, the website will be available at http://localhost:8000

## Git branches

- `main` — stable version for the production server
- `develop` — development branch
- `Auth` — authentication development
